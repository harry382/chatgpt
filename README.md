# 一起共读 · 微信读书会小程序

当前快照：1.1.0。1.1.0为第二版本；1.2.0为第三版本迭代。

这是脱敏的公开代码归档，不包含真实用户、活动照片、运营文档、备份、密钥和原始运行配置。公开历史与本机运营仓库分离；请勿向此仓库直接推送运营仓库的完整历史。

## 本地运行

1. 使用Node.js 20或以上版本运行 `npm run verify`。
2. 在微信开发者工具导入本目录。将project.config.json中的占位AppID换成自己的AppID。
3. 仅本机演示时，将miniprogram/config.js配置为generation: 2、mode: demo；演示数据仅能在develop环境运行。
4. 真实云模式需配置自己的云环境和readingClubV2云函数，创建club_v2_*集合并关闭客户端直接读写。安装云函数依赖，配置服务端身份、审核与可选订阅模板。
5. 发布前补全真实隐私联系邮箱和微信平台隐私声明，验证图片审核、地图和订阅提醒，完成真实手机验收和微信审核。
